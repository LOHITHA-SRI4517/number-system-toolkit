# 🔢 Number System Toolkit

A menu-driven **Number System Toolkit** developed using **C++**. The project provides basic number-system operations such as Decimal ↔ Binary conversion, Prime Number checking, and Palindrome Number checking.

## 📌 Features

* 🔄 Decimal to Binary conversion
* 🔄 Binary to Decimal conversion
* 🔍 Prime Number checking
* 🔁 Palindrome Number checking
* ✅ Input validation
* 🔢 Menu-driven interface
* 🧩 Uses functions, loops, and conditional statements

## 🛠️ Technologies Used

* **Language:** C++
* **Concepts:** Functions, Loops, Conditional Statements, Number Systems
* **Development:** Dev-C++ / C++ Compiler

## 💻 Core Operations

### 1. Decimal to Binary

Converts a decimal number into its equivalent binary representation.

### 2. Binary to Decimal

Converts a binary number into its equivalent decimal value.

### 3. Prime Number Check

Checks whether a given number is a prime number.

### 4. Palindrome Number Check

Checks whether a number remains the same when its digits are reversed.
